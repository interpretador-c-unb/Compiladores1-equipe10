## Decisões a serem feitas

## Palavras reservadas
- `IF` `ELSE` `WHILE` `FOR` `RETURN`
- `INT` `CHAR` `FLOAT` `VOID`

## Identificadores
- `ID` — nome de variável/função (`x`, `soma`, `_tmp`)
- `NUM` — número (`42`, `-3`, `3.14`)
- `STRING` — `"texto"`
- `CHARLIT` — `'a'`

## Operadores
- `ASSIGN` `=`
- `PLUS` `MINUS` `STAR` `SLASH` `PERCENT` → `+ - * / %`
- `EQ` `NE` `LT` `GT` `LE` `GE` → `== != < > <= >=`
- `ANDAND` `OROR` `NOT` → `&& || !`
- `PLUSPLUS` `MINUSMINUS` → `++ --`

## Delimitadores
- `LPAREN` `RPAREN` `( )`
- `LBRACE` `RBRACE` `{ }`
- `LBRACK` `RBRACK` `[ ]`
- `SEMI` `;`
- `COMMA` `,`
